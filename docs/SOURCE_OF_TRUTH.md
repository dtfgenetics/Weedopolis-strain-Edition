# Weedopolis — Source of Truth

`dtfgenetics/Weedopolis-strain-Edition` is the canonical code and machine-readable production repository for Weedopolis: Strain City Edition.

Google Drive `04 Games/Weedopolis` is canonical for approved human-readable rules, board/art masters, property/deed print masters, card art, money/tokens, playtest records, proofs, and release packages.

ChatGPT Library `DTF Working Projects/02 Games/Weedopolis` and `DTF Working Projects/02 Games/Hexagon weedopolis v2` are working/recovery surfaces only. V2/hexagon work must be reconciled into the single Weedopolis project rather than creating a second top-level master.

## Locked machine sources

- `data/board_map.csv` — official 40-space board map.
- `data/asset_registry.csv` — asset checklist.
- `data/color_groups.csv` — property color structure.
- `data/game_config.json` — core game configuration.
- `docs/WEEDOPOLIS_PRODUCTION_BIBLE.md` — locked design/game rules.

## Change rules

- Do not create a replacement Potopoly/Weedopolis production repo.
- Do not generate a final board as one uncontrolled image; preserve layered production.
- Resolve any disagreement between Library working files and canonical Drive/GitHub sources before promotion.
- Superseded versions go to archive/quarantine, not into release folders.

## Release

Use the DTF portfolio release criteria plus the Weedopolis production bible. A release must validate the 40-space board, property/color/price data, deed/card alignment, outward orientation, print dimensions, and digital/physical rule consistency.
