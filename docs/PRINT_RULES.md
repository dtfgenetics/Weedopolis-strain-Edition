# Weedopolis Print Rules

## Board

- Target master board size: 20 in x 20 in.
- Minimum final print resolution: 300 DPI.
- Keep bleed and no-bleed exports separate.
- Do not stretch, squash, or crop the board.

## Cards

- Ownership cards must use one locked physical size.
- Draw cards must use one locked physical size.
- Print sheets must use equal spacing.
- Text, names, prices, and numbers must stay readable.
- Property colors must match the board and color group data.

## Approved-source rule

Master images belong in source-approved folders. Web and print exports must be copies, not replacements.
