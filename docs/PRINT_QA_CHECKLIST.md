# Weedopolis Print QA Checklist

Use this before approving board, card, money, token, or piece exports.

## Board QA

- Exactly 40 spaces.
- Four corners.
- Ten spaces per side.
- All spaces face outward.
- Names and prices are readable.
- No accidental crop or cutoff.

## Card QA

- Same card type uses the same physical size.
- All cards are centered on print sheets.
- No stretched artwork.
- No clipped borders.
- Board names and prices match source data.

## Asset QA

- Source files are preserved.
- Web exports are separate.
- Print exports are separate.
- Missing approved images are reported before final export.
